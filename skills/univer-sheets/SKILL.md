# Univer Sheets Integration Guide

## Core Capabilities
- **Direct Spreadsheet API**: Manipulate cells, formulas, formatting, filters, and sheets via Univer core API.
- **Civil BOQ and KPK MRS Automation**: Compute line item totals, composite rates, and District Location Factors in real-time.
- **Export & Import**: Native compatibility with XLSX, CSV, and reactive web app embedding.
