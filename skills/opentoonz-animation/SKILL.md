# OpenToonz Production Animation Guide

## Overview

`OpenToonz` (`opentoonz/opentoonz`) is an open-source 2D animation software suite based on the proprietary "Toonz" software customized and utilized by Studio Ghibli. It provides full digital pipeline capabilities from scanning paper drawings to digital ink-and-paint, compositing, and effects.

Repository Path: `C:\tools\opentoonz`

---

## Capabilities

1. **GTS (Scanning Tool)**: Clean-up and vectorization of pencil line tests and sketches.
2. **Xsheet (Exposure Sheet)**: Traditional multi-layer frame timing, audio scrub synchronization, and exposure timing.
3. **Node-based Schematic FX**: Built-in compositing tree for lighting, blur, particles, and chromatic aberration effects.
4. **Vector & Raster Levels**: Resolution-independent vector lines with automated fill and palette indexing.
