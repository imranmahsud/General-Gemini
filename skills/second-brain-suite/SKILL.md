# Second Brain Suite

A suite of 9 interconnected repositories located at `C:\tools\second-brain-suite\` that turn static project notes and engineering documentation into a self-maintaining second brain.

## Suite Repositories (`C:\tools\second-brain-suite\`)

1. **`llm-wiki`** (`C:\tools\second-brain-suite\llm-wiki`): Karpathy's LLM-wiki blueprint where agents digest raw notes, web sources, and project logs into an interlinked markdown knowledge graph.
2. **`gbrain`** (`C:\tools\second-brain-suite\gbrain`): Garry Tan's second brain engine for automated thought-capturing and retrieval.
3. **`obsidian-skills`** (`C:\tools\second-brain-suite\obsidian-skills`): Vault automation, link integrity, and markdown structure manipulation.
4. **`knowledge-work-plugins`** (`C:\tools\second-brain-suite\knowledge-work-plugins`): Anthropic knowledge worker workflows and document digest templates.
5. **`openai-skills`** (`C:\tools\second-brain-suite\openai-skills`): Prompt patterns and tool chains for memory extraction.
6. **`khoj`** (`C:\tools\second-brain-suite\khoj`): Offline, privacy-first personal AI assistant for desktop notes and documents.
7. **`ai-memory`** (`C:\tools\second-brain-suite\ai-memory`): Semantic retrieval and temporal context layering.
8. **`basic-memory`** (`C:\tools\second-brain-suite\basic-memory`): Zero-dependency key-value and vector memory store.
9. **`COG-second-brain`** (`C:\tools\second-brain-suite\COG-second-brain`): Cognitive architecture for hierarchical thought mapping.

## Usage in Agent Process

- **Memory Synthesis**: When ingesting new project specifications (e.g. KPK MRS rates, engineering codes), compile them into atomic wiki pages in your vault.
- **Cross-Session Recall**: Query `basic-memory` or `khoj` local search before executing multi-day tasks to recall past decisions and file paths.
