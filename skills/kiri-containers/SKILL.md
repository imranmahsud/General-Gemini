# Kiri Containers Guide

## Core Capabilities
- **Lightweight Daemon**: High performance container orchestration written in Rust without Docker Desktop memory overhead.
- **Built-in Share Link**: Instant secure HTTPS tunnels for running containers using `kiri share <container>`.
- **Compose Compatibility**: Runs standard docker-compose and Dockerfile recipes out of the box.

## Local Files
- Path: `C:\tools\kiri`
